# CropBuddy — Team QuadX

Responsive, farmer-friendly React website prototype with English, Telugu, and Hindi, a farm analysis form/report, ResidueLink marketplace demo, and farmer guide.

## Run in Visual Studio Code
1. Install Node.js LTS: https://nodejs.org/
2. Extract this ZIP and open the `CropBuddy_GitHub` folder in VS Code.
3. Open Terminal → New Terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed in the terminal (usually http://localhost:5173).

## Build
```bash
npm run build
npm run preview
```

## GitHub
Create a new repository and upload the contents of this folder to its root. To make it a live website, configure a Vite deployment workflow or use Vercel/Netlify; uploading source code alone does not publish a Vite app.

## Important limitations
Student prototype only. Reports use simple illustrative rules, not a trained AI model or verified agronomic diagnosis. No live weather, soil lab, verified buyers, authentication, or remote database is connected. Residue listings are local demo data and are not shared between users. Consult a soil test and local agriculture officer/KVK for farm-specific decisions.
